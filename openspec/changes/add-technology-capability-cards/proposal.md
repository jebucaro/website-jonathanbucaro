## Why

The home page technology section currently presents logos with only a name tooltip, which does not explain the value Jonathan can deliver with each technology. Visitors need a compact, visually coherent way to connect the technical stack to client outcomes.

## What Changes

- Replace the icon-only technology presentation with compact technology cards that retain each technology's logo and name.
- Organize cards into Backend & Integrations, Web Applications, and Automation, APIs & Content capability groups.
- Add short, client-outcome-oriented descriptions for each technology.
- Reveal card details through pointer hover and keyboard focus while keeping essential content available on touch devices.
- Preserve the site's restrained visual language, responsive layout, dark mode, and motion preferences.

## Capabilities

### New Capabilities

- `technology-capability-cards`: Present the home page technology stack as grouped, accessible cards that relate each technology to a client outcome.

### Modified Capabilities

- None.

## Impact

- Affects the Hugo home page technologies partial, technology-section styles, and technology entries in the site parameters.
- Does not add runtime dependencies or alter project content, navigation, or external APIs.
